# House rules

- Keep it simple: skills are plain-text instructions. Add code only when instructions cannot do the job.
- One folder per skill under skills/, each with a SKILL.md (see docs/skill-template.md).
- Never commit secrets. Logins live in the cloud environment's secrets.
- The user is not a seasoned developer: explain in plain language, ask clarifying questions first, present options and recommend one.
- Develop on the designated branch; do not open pull requests unless asked.
